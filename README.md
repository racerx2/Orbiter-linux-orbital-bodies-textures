# Orbiter 2027 Linux: planet and moon textures

Surface, mask, elevation and cloud tiles (TileFormat 2) for the planets and moons of
[Orbiter 2027 Linux](https://github.com/racerx2/orbiter-2027-linux).

The zips are in the [releases](https://github.com/racerx2/Orbiter-linux-orbital-bodies-textures/releases),
one per body and layer, named `<Body>_<Layer>.zip`. All 46 together are about 2.3 GB, and need about 5 GB once unpacked.

When a scenario is launched and textures are missing, Orbiter's Launchpad lists them and offers to
download and install them. To install by hand, unzip a pack into the Orbiter folder; it adds
`Textures/<Body>/<Layer>`.

`md5.txt` has the checksums, `CREDITS.txt` the map sources and licences.
